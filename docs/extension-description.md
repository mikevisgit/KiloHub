# Kilo Hub

Ваши папки с диалогами Kilo Code в одной панели VS Code. Находите нужную работу по названию папки, диалога или словам из своих сообщений и быстро возвращайтесь к ней.

## Как пользоваться

Откройте Kilo Hub на боковой панели Activity Bar. Раскройте карточку папки, чтобы увидеть до трёх последних диалогов и доступные действия.

- Откройте папку в текущем или отдельном окне VS Code.
- Покажите её файлы в Проводнике Windows.
- Наведите указатель на название папки, чтобы увидеть полный путь.

Текущая папка отмечена «Вы сейчас здесь». Недоступная папка остаётся в истории, но действия её открытия отключены. Названия диалогов служат ориентиром: продолжить общение можно в самом Kilo Code.

## Поиск и обновление

Введите запрос над списком: поиск обновится автоматически после короткой паузы в наборе (300 мс). Enter запускает его сразу. Поиск учитывает названия папок, все подходящие диалоги и текст ваших сообщений. Во всём запросе нужно не менее трёх символов; короткие слова внутри разрешены, например «бот в тг» или «UI UX». Можно вводить части слов. Регистр не важен, «е» и «ё» равнозначны. Все слова должны встретиться в истории одной папки, но могут находиться в разных диалогах или сообщениях.

Очистка поля, крестик или Escape сразу возвращают полный список. Пока вы быстро печатаете, поиск ждёт паузы и не запускается на каждый символ. Фоновое обновление сохраняет уже применённый запрос. После перезагрузки окна запрос сбрасывается. Результаты показывают папки, без цитат: в раскрытии остаются обычные три последних диалога.

Данные обновляются автоматически и могут появляться с задержкой. Первичная подготовка может занять несколько минут и не требует прекращать работу. Пока результаты неполные, показано «Подготавливаем поиск…». При временной ошибке сохраняются последние доступные данные, попытки обновления повторяются автоматически.

## Начать работу в другой папке

Нажмите плюсик и выберите существующую папку. Она откроется в текущем окне VS Code; штатные предупреждения о несохранённых файлах сохраняются.

Текущая папка без диалогов получает первую карточку с отметкой «Пока без диалогов Kilo» и пояснением внутри. После начала общения информация появится автоматически. Если уйти из папки, не создав диалог, она не останется в истории Hub. При поиске эта карточка также фильтруется по названию.

## Требования

- Windows x64.
- VS Code 1.105.1 или новее в пределах версии 1.x.
- Kilo Code 7.7.5 или новее с совместимым форматом локальной истории.

Отдельно устанавливать Node.js, npm, SQLite или Kilo CLI не требуется.

## Ограничения

Поддерживаются локальные папки Windows. Сетевые пути, Remote SSH, WSL, Dev Containers и рабочие области с несколькими папками не поддерживаются. Архивные и дочерние диалоги не входят в список.

Поиск не включает ответы ассистента, результаты инструментов и содержимое вложений или файлов проектов. При неподдерживаемом формате истории обновление приостанавливается с предупреждением. Отдельные диалоги нужно открывать и продолжать в самом Kilo Code.

Hub не изменяет историю Kilo и не отправляет данные в сеть.
