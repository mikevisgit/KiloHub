# Kilo Hub

Ваши папки с диалогами Kilo Code в одной панели VS Code. Быстро возвращайтесь к работе, не вспоминая, где лежит нужный проект.

## Как пользоваться

Откройте Kilo Hub на боковой панели Activity Bar. Раскройте карточку папки, чтобы увидеть до трёх последних диалогов и доступные действия.

- Откройте папку в текущем или отдельном окне VS Code.
- Покажите её файлы в Проводнике Windows.
- Наведите указатель на название папки, чтобы увидеть полный путь.

Текущая папка отмечена «Вы сейчас здесь». Недоступная папка остаётся в истории, но действия её открытия отключены. Названия диалогов служат ориентиром: продолжить общение можно в самом Kilo Code.

## Требования

- Windows x64.
- VS Code 1.105.1 или новее в пределах версии 1.x.
- Kilo Code 7.7.5 или новее с совместимым форматом локальной истории.

Отдельно устанавливать Node.js, npm, SQLite или Kilo CLI не требуется.

## Ограничения

Поддерживаются локальные папки Windows. Сетевые пути, Remote SSH, WSL, Dev Containers и рабочие области с несколькими папками не поддерживаются. Архивные и дочерние диалоги не входят в список.

Hub не изменяет историю Kilo и не отправляет данные в сеть.
