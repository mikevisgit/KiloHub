## Перед началом

1. В VS Code выполнить `Developer: Reload Window`, чтобы работающий Extension Host загрузил установленную версию `0.2.0`.
2. Открыть Activity Bar `Kilo Hub`.
3. Убедиться, что сверху видны только `Kilo Hub` и `Мои папки с Kilo`; строки `Kilo Folders` нет.

## Короткая проверка финала

1. Текущая папка находится первой и помечена `Вы сейчас здесь`.
2. Карточки имеют монограммы; цвета читаемы и меняются вместе с темой VS Code.
3. Раскрывается максимум одна карточка; быстрые повторные клики не оставляют промежуточное состояние.
4. В карточке показано не более трёх последних названий диалогов; они не являются кнопками.
5. Tooltip полного пути открывается мышью и клавиатурой, остаётся при переходе на popup и закрывается `Escape`.
6. Обычная доступная папка имеет три действия; текущая — только Проводник; missing — без действий.
7. `Refresh` показывает состояние обновления и не удаляет старый список при ошибке.
8. Проверить тёмную, светлую и high-contrast темы, ширину Side Bar примерно 260/320/400 px и zoom 100/200%.
9. Проверить navigation только клавиатурой: `Tab`, `Shift+Tab`, `Enter`, `Space`, `Escape`.
10. Реальные folder actions выполнять только на disposable/test папке, чтобы не потерять текущее окно.

Полный нормативный checklist: `req/step2/04-manual-acceptance-checklist.md`.
