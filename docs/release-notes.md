# Kilo Hub 0.3.0

## Назначение

Kilo Hub помогает возвращаться к папкам с диалогами Kilo Code. Step 3 добавляет автоматическое обновление, поиск по названиям и вашим сообщениям, выбор новой папки и полноценное описание страницы расширения.

## Новое в 0.3.0

- список обновляется в фоне, ручная кнопка Refresh больше не нужна;
- поиск по Enter учитывает названия папок, все подходящие диалоги и пользовательские сообщения;
- в каждом слове запроса нужно не менее трёх символов; крестик или Escape снимают фильтр;
- плюсик открывает выбранную существующую папку в текущем окне;
- текущая папка без диалогов получает временную карточку с пояснением, без регистрации в истории;
- сохранены только подсказки у info, плюсика и названия папки с полным путём;
- вкладка Details содержит русское описание функций и ограничений;
- первоначальная подготовка может занимать несколько минут; отставание допускается, готовые результаты доступны с отметкой о неполноте;
- новые сообщения не обнуляют завершённую подготовку, обычное обновление обрабатывает изменившиеся диалоги;
- повторный поиск по проверенному поколению не запускает заново полную проверку целостности.

## Исправления 0.2.3

- единственная подсказка полного пути появляется только при наведении на текст названия папки;
- наведение на остальную плашку, info, refresh и действия не показывает подсказок;
- keyboard focus не показывает popup, полный путь остаётся доступен через ARIA;
- PNG страницы расширения использует актуальный знак Kilo вместо стандартной заглушки VS Code.

## Исправления 0.2.2

- убраны подсказки у заголовка `Последние диалоги` и отдельных названий диалогов;
- полные названия диалогов остаются доступны screen reader без лишних Tab-stop;
- popup подсказки не перехватывает указатель и немедленно исчезает при попадании курсора в его прямоугольник;
- скрытая подсказка не появляется повторно, пока указатель не покинет её источник.

## Исправления 0.2.1

- подписи `Вы сейчас здесь` и `Папка не найдена` скрыты у карточек, к которым они не относятся;
- убран стандартный внешний padding Webview, поэтому список плотнее примыкает к краям Side Bar;
- карточки и раскрытые действия занимают всю доступную ширину без горизонтального переполнения;
- тонкая рамка и фон применяются к отдельным карточкам, а не к оболочке всей панели.

## Возможности Step 2 (история)

- представление `Kilo Hub` типа Webview в прежнем Activity Bar container;
- карточки папок с устойчивыми монограммами и адаптацией к теме VS Code;
- текущая папка всегда первая и помечена `Вы сейчас здесь`;
- доступный аккордеон с сохранением фокуса и позиции;
- полный путь при наведении на название папки и через ARIA-описание кнопки карточки;
- до трёх последних названий диалогов без возможности открыть диалог;
- три действия для обычной доступной папки, только Проводник для текущей, отсутствие действий у missing;
- сортировка по времени последней Kilo-активности;
- ручной `Refresh` внутри Webview;
- состояние missing для удалённой или недоступной папки;
- read-only чтение metadata из `kilo.db` с учётом WAL;
- работа без отдельной установки Kilo CLI и без сети.

## Поддерживаемая среда

- Windows x64;
- VS Code `1.105.1` или новее в пределах major `1.x`;
- Kilo Code `7.7.5` или более новая версия с совместимым форматом локальной истории;
- текущая локальная Kilo database/environment.

## Ограничения

Step 3 не поддерживает:

- `.code-workspace` и multi-root workspaces;
- UNC paths;
- mapped network drives и reparse points, которые разрешаются в UNC target;
- Remote SSH, WSL и Dev Container paths/URI;
- архивные и дочерние agent sessions;
- открытие конкретного Kilo-диалога;
- ручной постоянный реестр папок без диалогов, удаление или скрытие папок из истории;
- импорт VS Code `Open Recent`;
- legacy task JSON;
- summary, LLM, embeddings, поиск по ответам ассистента, результатам инструментов и содержимому вложений;
- Hub API, MCP, telemetry и облачную синхронизацию.

Папка, удалённая с диска, остаётся в списке, пока в Kilo существует связанная session. Действия открытия такой папки заблокированы.

## Конфиденциальность и данные

Поиск работает локально по метаданным и допустимым текстам пользовательских сообщений. Содержимое файлов проектов не читается, переписка не выводится в диагностические логи. История Kilo доступна только для чтения и не изменяется. При ошибках сохраняются последние доступные данные; при неподдерживаемом формате нельзя объявлять поиск полным.

## Сборка

Версия распространяется как platform-specific пакет `kilo-hub-0.3.0-win32-x64.vsix`. Точный checksum и результаты release gate записываются в корневой `handoff.md`, который не включается в runtime-пакет. Наличие этих notes в исходниках само по себе не означает прохождение release gate.
