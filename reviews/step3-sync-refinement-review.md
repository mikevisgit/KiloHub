## SYNC-08

Реализация durable очереди/атомарной замены диалога и связанные backend tests находятся в работе. Общий npm test, независимое review движка и выпуск VSIX pending.

Первый integrated npm test прошёл typecheck/lint и восемь первых unit cases, затем превысил 900 s на прежнем тесте 10001 диалога. Найдена новая регрессия: отдельный COMMIT каждой scratch census строки на каждой порции. Исправление ограничено bounded metadata census transactions (100 строк/256 KiB), прежние per-part записи не меняются. Увеличение timeout не считается исправлением; процесс timed-out теста PID8292 после завершения отсутствовал.

Независимое ревью нового census block не нашло ошибок rollback/границ/условий удаления. Открытый Medium: crash между commit первого готового диалога и первым published pointer может скрыть готовую часть при последующей ошибке следующего диалога. Требуется recovery-публикация проверенной части building до попытки следующего work item и отдельная regression; это передано исполнителю.
