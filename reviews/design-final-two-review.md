# Проверка двух финальных эталонов Kilo Hub

## Результат

В историческом отчёте сравнивались две композиции. Актуальная [галерея](../req/step2/variants/index.html) содержит выбранные [Монограммы](../req/step2/variants/01-monograms.html); отменённые [Тонкие рамки](../req/step2/old_donotuse/variants/vscode-monograms/02-inset.html) сохранены только в архиве. [Финальное ТЗ](../req/step2/ТЗ%20реализации%20дизайна%20VSIX.md) предназначено будущему агенту реализации.

Обе композиции сохраняют различия: монограммы — знаки 51 px, названия 20 px, отдельные округлые карточки 15 px и исходная пастельная палитра; рамки — знаки 34 px, названия 17 px, тонкие компактные блоки 4 px. Это факты CSS, не оценка изображения.

## Выполненные проверки

- Синтаксис build-final.mjs, demo.js, activity.cjs проходит `node --check`; HTML пересобраны `node desing/variants/build-final.mjs`.
- `node desing/variants/verify-final.mjs` проходит: ровно 3 HTML (галерея + 2 эталона), 7 тематических панелей; все локальные ссылки и якоря действующих документов; нет внешних ресурсов/запросов.
- Каждая панель содержит пять обезличенных папок, одну текущую и одну изначально раскрытую, missing с тремя aria-disabled действиями, длинное название. Всего 13 пассивных названий на панель: до трёх на папку. Нет дат диалогов, списка с маркерами, строки полного пути, постоянных пояснений.
- Реальная функция дат проверена на границах 0/1/2/6/7/13/14/20/21/29/30/59/60/364/365/730/1825, неизвестной/невалидной/будущей дате и переходе полуночи менее чем за 24 часа. Проверен порядок текущая старая → новая → неизвестная.
- Расчёт 11 пар текста/фона на палитру, включая hover и дату на current-background: минимум original 5,54:1; dark 4,79:1; light 4,74:1; contrast 13,44:1. Это расчёт явных демо-палитр, не всех rendered пикселей/пользовательских тем. Forced colors и focus предусмотрены в CSS; фактический рендер не проверен.
- По исходнику аккордеон синхронно снимает aria-expanded с предыдущей папки; скрытые детали inert; возврат фокуса из закрываемой области; 160 мс через requestAnimationFrame, reduced motion — нулевая длительность. Компенсация по координате выбранной плашки ограничена собственным scroll-container. Дополнительная прокрутка только для видимости плашки/начала деталей; край списка естественно ограничивает компенсацию. Это анализ кода, не runtime-проверка.
- Команды только сообщают о демонстрации; aria-disabled проверяется обработчиком. Источник Kilo, сеть и VS Code API не вызываются. Tooltip поддерживает focus/hover, Escape и удержание курсором.
- Удаление выполнено явным списком 33 устаревших файлов после проверки новых зависимостей. Первоначальная массовая команда была отклонена автоматической проверкой и не выполнялась; безопасная операция после устранения риска разрешена. Скриншоты, Step 1, production, VSIX и данные не изменены.

## Ограничения и следующий шаг

Browser Use ранее запретил file URL и обходы, поэтому браузер не использовался. Визуальный рендер, клавиатурное поведение/чтение screen reader, анимация, быстрое повторное нажатие, scroll на краю и 200% zoom остаются ручной приёмкой. Проверка сбалансированности CSS не заменяет браузерный CSS parser. Проверки статических ссылок и расчёт контраста не являются E2E.

Loading/empty/error/stale/refresh подробно определены в финальном ТЗ; текущие эталоны демонстрируют нормальное и missing-состояния. Автономные палитры не следуют теме редактора. Выбрать одну из двух композиций перед production; переключатель дизайнов не нужен. ТЗ охватывает Webview-интеграцию, безопасность сообщений/CSP/read-only metadata и будущие VSIX-проверки.
