# Повторный аудит применения UX-правок

Проверены текущие файлы после `883898f`, а не только прошлый отчёт. Макеты и код не изменялись. Основание: `desing/UX правки.md`, `desing/ТЗ реализации дизайна VSIX.md`. Браузер не использовался; ниже разделены исходники, офлайн-пробы и непроверенный runtime.

## Подтверждённые несоответствия

1. **P1 — неверный полный путь у всех 35 папок, пункт 19 не выполнен.** `desing/variants/build-final.mjs:9` содержит неэкранированные обратные слеши перед шаблонной подстановкой. В обоих фактических HTML, строка 1, все `class="name" data-tip` имеют буквальное значение `D:Примеры${esc(name)}`: 20 у монограмм, 15 у рамок. `demo.js:7` копирует эту же строку на клавиатурную плашку. Пользователь не получает путь и не может различить одинаковые имена. Проверено извлечением значений из готовых HTML; это не гипотеза рендера.
2. **P2 — подсказка с фокусом исчезает от движения мыши.** `desing/variants/demo.js:42` безусловно планирует hide при pointerout; строки 39 и 43 также не учитывают сохранённый фокус. Офлайн VM-проба реальных обработчиков: focusin → tooltip виден; pointerout при том же document.activeElement + выполнение таймера → tooltip скрыт. Это расходится с доступностью подсказки по фокусу (пункты 6, 13, 18–23 и общее ТЗ). Браузерное поведение screen reader не проверено.
3. **P2 — быстрый следующий выбор теряется, пункт 17 выполнен частично.** `demo.js:11` возвращает управление при running, без очереди или отмены предыдущего перехода; анимация длится 160 мс по строке 21. Нажатие другой папки в этот интервал не меняет выбранное раскрытие. Факт ветки кода подтверждён; частота неудобства в живом интерфейсе не измерялась.
4. **P2 — несуществующая календарная дата принимается как достоверная, пункт 13 частично.** `activity.cjs:2` проверяет только результат `new Date`, который нормализует некоторые ошибки. Реальная Node-проба: `2026-02-30T12:00:00Z` → `2026-03-02T12:00:00.000Z` → «6 месяцев назад» при now=2026-09-20; `2026-04-31` → 1 мая. Требуется «Дата неизвестна». Текущие обезличенные примеры используют корректные даты; это дефект помощника, не наблюдавшаяся ошибка текущей подписи.
5. **P2 — нет ограничения высоты длинной подсказки.** `refinements.css:1` задаёт max-width, но не max-height/overflow для `.tooltip`; `demo.js:40` ограничивает лишь верхнюю координату. Если высота текста 500 px при viewport 300 px, формула ставит top=8, bottom=508: текст выходит за viewport. Это доказанная граница алгоритма, не утверждение, что имеющиеся короткие примеры уже обрезались. Значимо для полного длинного пути/названия и увеличенного масштаба.
6. **P3 — подпись «Сегодня» не обновляется при смене дня.** `demo.js:3–8` вычисляет now и подписи только один раз. Таймера/пересчёта при возвращении на страницу нет; имитация refresh в строке 46 также даты не обновляет. ТЗ требует учитывать смену локального дня. Для краткого просмотра макета это ограничение демонстрации; будущая интеграция не должна копировать его.
