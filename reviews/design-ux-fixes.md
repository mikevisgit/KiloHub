# Исправления повторного UX-аудита

Основание: [аудит](design-ux-application-audit.md) и прямое разрешение пользователя исправить все замечания, замедлив анимацию вдвое. Меняются только локальные два макета и их зависимости/документация, не расширение.

| Замечание | Изменение | Проверка |
| --- | --- | --- |
| 1. Повреждённый путь | В генераторе экранированы Windows-разделители; оба HTML пересобраны | Все 35 data-tip точно равны `D:\Примеры\<название>`; нет буквальных шаблонных подстановок |
| 2. Tooltip теряет фокус | Отдельное состояние hover/focus/tooltip; закрытие только после выхода обоих, Escape подавляет повторное появление текущих владельцев | Офлайн реальные обработчики: focus + pointerout, переход к другому владельцу, Escape + старые таймеры, возврат с tooltip, focusout A → focusin B |
| 3. Потеря быстрых кликов | Очередь хранит последнее намерение; повторный выбор означает закрытие | A→B→C, B→B, A→B→A→C, серия многих нажатий; обычный и немедленный переход. Проверяется реальный queue helper |
| 4. Невалидные даты | Строгая проверка ISO timestamp, календарных дней/високосности/времени/offset перед Date | 30 февраля, 31 апреля, 1900/2000/2024/2025, будущие, корректные +/- timezone и базовые границы |
| 5. Высокий tooltip | max-height/width от viewport, overflow:auto, доступность прокрутки фокусом; координата без зазора между владельцем и tooltip | Офлайн проверены лимиты размера и переход owner→tooltip; браузерное clipping/zoom остаётся ручной проверкой |
| 6. Смена дня | Fixture timestamps закреплены в HTML; пересчёт подписей при локальной полуночи, focus, visibility и refresh | Сегодня→Вчера при неизменном timestamp, сохранение current-first; прочитан код планирования/обновления без записи активности |

Длительность обычного перехода — **320 мс**, единая константа `HubInteraction.ANIMATION_MS`. Reduced motion — 0; логика компенсации положения сохранена. UX пункт 17 и итоговое ТЗ обновлены. Очередь выполняет последний запрос после текущего перехода, не объявляет выполненным потерянное нажатие.

Проверки: `node desing/variants/build-final.mjs`; `node --check` для demo.js, activity.cjs, interaction.cjs и build-final.mjs; `node desing/variants/verify-final.mjs`; `node desing/variants/verify-regressions.mjs`; `git diff --check`. Два дизайна, семь тем, локальные ссылки и расчёт палитр сохранены.

Это исходники и офлайн-пробы; полный DOM/рендер, screen reader, настоящая прокрутка, анимация и 200% zoom не проверены. Браузерный запрет не обходился. Независимое ревью исправлений и визуальная приёмка отдельно; этот документ не объявляет их выполненными.

Дополнительная независимая проверка выявила переход tooltip к владельцу соседней тематической панели. Исправлено ограничением panel.contains; офлайн-регрессия ухода к чужому элементу проходит.
