# Общая мягкая палитра16групп

Применена во всех7темах/112знаках, включая original. Точные прежние mint/peach/lavender/blue заливки взяты как опорные из эталона перед d1ef061; таблица16светлых цветов записана в ТЗ. Dark — приглушённые оттенки24% насыщенности/28% светлоты. Инициалы тёмные/светлые с проверкой≥4,5:1; хэш и нормализация путей не изменены.

В обычных темах граница знака transparent (геометрический резерв1px сохранён), рамки карточек не тронуты. HC добавляет границу только когда заливка не достигает3:1 к поверхности; forced-colors сохраняет системную читаемость. Missing не превращается в серый. Все16групп представлены в каждой панели; набор/порядок/даты/условные действия/320мс сохранены.

Проверки: verify-colors (112групп, нормализация,4096RGB×16слотов, инициалы минимум6,24:1, HC-границы при необходимости минимум4,58:1; normal transparent и переходы HC-dark/HC-light→normal на реальном обработчике с DOM-дублем), verify-final/regressions/scale, node --check новых модулей/генератора, git diff --check. Сравнение исходников и математика не доказывают фактический браузерный рендер/пользовательское восприятие/VSIX. Никакого обхода browser policy, production и данные не изменены.

Независимое ревью:112знаков/7тем, точные пастельные anchors, победа финального CSS над прежними border-правилами, отсутствие mono outline/shadow и фактические inline fg/bg проверены.7000разных пар surface/edge подтвердили условный HC-контур и отсутствие normal-контура; CJS/global API совпадают. Значимых дефектов нет, рендер не подтверждён.
