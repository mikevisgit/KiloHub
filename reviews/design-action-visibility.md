# Проверка видимости действий папок

По принятому уточнению пользователя изменён только Step 2: в текущей доступной папке одна второстепенная команда Проводника; в остальных доступных — три; в missing нет кнопок и контейнера действий. Missing приоритетнее current. История и предупреждение сохраняются, верхние разделитель/отступы истории без команд убраны. Знаки папок в этом изменении не затрагивались.

Проверено по всем семи тематическим представлениям: точное количество кнопок в каждой карточке, отсутствие actions у missing, сохранность истории/активности, отсутствие aria-disabled-заглушек. Прямой вызов renderActions проверил четыре сочетания current/missing, включая оба true. Единственный Проводник не получает стиль первичной команды открытия.

Прошли генерация, verify-final.mjs, verify-regressions.mjs, verify-scale.mjs и git diff --check. Даты, current-first, очередь аккордеона320мс и tooltip-регрессии сохранены. Это исходниковая/офлайн проверка; реальный браузерный рендер, фокус и геометрия не проверялись. Production, VSIX и req/step1 не менялись.
