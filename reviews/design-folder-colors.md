# 16 цветовых групп — проверка макетов

Реализованы UX26 и расширенное ТЗ: общая группа FNV-1a нормализованного полного локального Windows-пути. Никакого реестра или ручной настройки. Только знак окрашивается; формы32/36px при B13, статусы, условные команды, даты, tooltip и320мс сохранены.

В двух HTML112плашек:16в каждой из7панелей, по одному примеру каждой группы. Demo-имена с числовыми суффиксами подобраны до покрытия хэшей0–15; production не подбирает/меняет пути ради палитры. Одинаковая последовательность между темами, current первый с более старой активностью, missing последний. Доступ к полному списку — обычная прокрутка панели.

`verify-colors.mjs`:112path/group,16слотов, одинаковые обе композиции/темы; эквивалентные регистр/слеши/dot/trailing и невалидные пути. Для4096RGB-поверхностей×16слотов минимум контраста букв7,70:1, границы4,58:1. Отдельно реальный обработчик folder-colors.js на офлайн DOM-дубле: dark→light→HC-dark→HC-light→нестандартный CSS-color→focus, группа неизменна; fallback Canvas/CanvasText, перестановка строк не меняет цвета.

`verify-final.mjs`, `verify-regressions.mjs`, `verify-scale.mjs`, `node --check` новых модулей и `git diff --check` проходят. Это проверки исходников/алгоритмов, не фактический computed style в браузере. Нет доказательства визуальной различимости всех16цветов для всех тем/людей; совпадения групп допустимы, forced-colors сознательно может убрать оттенки. Runtime-проверка VS Code/клавиатуры/рендера остаётся отдельным этапом. Production и данные Kilo не тронуты.

Независимый reviewer подтвердил1920эквивалентных вариантов путей, parity CJS/browser-global API, все112знаков,7000случайных RGB-поверхностей (минимумы7,70/4,58), alpha-композицию resolveSurface и fallback нестандартных цветов. Значимых дефектов не найдено; визуальный рендер этим не подтверждён.
