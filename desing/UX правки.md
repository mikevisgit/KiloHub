# UX правки — «Тонкие рамки»

Рабочий список предложений для ручной правки. Решения применены к двум локальным макетам; интеграция в расширение ещё не выполнена.

Основа: [выбранный макет](variants/vscode-monograms/02-inset.html) и [ревью для новичка](../reviews/design-inset-novice-top20.md). Сохранены исходные номера оставшихся замечаний. Принятые решения отмечены явно; остальные пункты остаются предложениями. Пункт 17 принят по команде выполнить все правки.

## 1. Понятное действие перехода

**Проблема:** «Открыть в этом окне» не объясняет, что выбранная папка заменит текущую.

**Принятое решение:** сохранить название действия **«Открыть в этом окне»**. Постоянное пояснение не добавлять, чтобы не раздувать интерфейс.

Подсказка при наведении: **«Выбранная папка откроется вместо текущей в этом окне VS Code»**.

## 3. Последние диалоги — компактный блок для ориентира

**Принятое решение:** заголовок **«Последние диалоги»**, под ним до трёх названий, каждое с новой строки, без маркеров списка.

Убрать постоянные пояснения к блоку. Даты диалогов не показывать: достаточно даты последней активности на плашке папки. Уменьшить вертикальные интервалы между названиями.

Названия остаются пассивным текстом без оформления кнопок и подсветки при наведении.

## 6. Объяснить, какие папки попадают в список

**Проблема:** «Ваши папки» можно понять как все папки на компьютере.

**Принятое решение:** заголовок **«Мои папки с Kilo»**. Рядом — небольшой значок информации; постоянный дополнительный текст не добавлять.

Подсказка при наведении на значок: **«Здесь собраны папки, в которых вы работали с Kilo. Чтобы вернуться к работе, выберите папку и откройте её.»**

## 7. Отличать текущую папку от раскрытой

**Проблема:** раскрытую папку можно принять за место, где сейчас идёт работа.

**Принятое решение:** текущая открытая папка всегда первая независимо от давности её диалогов. Остальные папки идут по убыванию последней Kilo-активности. Простое открытие папки не меняет дату Kilo-активности.

У текущей папки постоянно показывать **«Вы сейчас здесь»** и устойчивый визуальный акцент независимо от раскрытия. Раскрытие другой папки не даёт такого же выделения, а только показывает детали.

## 8. Объяснить отдельное окно

**Проблема:** новичку неясно, чем второе окно отличается от перехода в текущем.

**Принятое решение:** второстепенное действие **«Открыть в отдельном окне»**. Подсказка при наведении: **«Текущая папка останется открытой»**. Постоянное пояснение не добавлять.

## 9. Объяснить переход в Проводник

**Проблема:** «Показать в проводнике» может не объяснять, где окажется пользователь.

**Принятое решение:** применять пункт 18 — действие **«Показать файлы папки»** с пояснением только в подсказке при наведении, без постоянного текста.

## 13. Последняя активность внутри каждой плашки папки

**Проблема:** по свёрнутым папкам трудно понять, когда в них работали с Kilo.

**Принятое решение:** по уточнению пользователя показывать последнюю Kilo-активность **внутри каждой плашки папки**, без дополнительной строки над списком. Название остаётся главным, дата — второстепенной.

Относительная дата видна уже на **свёрнутой плашке рядом с названием** и сохраняется при раскрытии.

Считать разницу между календарной датой активности и сегодняшней датой **в локальном часовом поясе пользователя**, а не количество полных 24-часовых периодов. Сначала проверить исходную дату: отсутствующая, некорректная или будущая дата даёт подпись **«Дата неизвестна»**, без выдуманной активности. Будущей считается и дата позже текущего момента в пределах сегодняшнего дня.

| Прошло календарных дней | Подпись |
| --- | --- |
| 0 | **«Сегодня, чч:мм»**, например «Сегодня, 14:35» |
| 1 | **«Вчера»** |
| 2–6 | **«N дня/дней назад»**, например «2 дня назад», «5 дней назад» |
| 7–13 | **«Неделю назад»** |
| 14–20 | **«2 недели назад»** |
| 21–29 | **«3 недели назад»** |
| 30–59 | **«Месяц назад»** |
| 60–364 | Число месяцев = `floor(дни / 30)`: «2 месяца назад», «5 месяцев назад» |
| 365 и больше | Число лет = `floor(дни / 365)`: «Год назад», «2 года назад», «5 лет назад» |

Числа склонять по правилам русского языка: окончания 11–14 — «дней / месяцев / лет»; в остальных случаях последняя цифра 1 — «день / месяц / год», 2–4 — «дня / месяца / года», остальные — «дней / месяцев / лет». Для одного года использовать **«Год назад»**. Месяцы и годы здесь — приблизительные интервалы для ориентира, а не точные календарные сроки.

Часы и минуты в **24-часовом формате чч:мм** показывать **только для сегодняшней активности**. Для остальных подписей время не показывать. В обсуждении обозначение «дд:мм» уточнено как часы и минуты — «чч:мм».

Подсказка при наведении: **«Последняя активность в Kilo»** с точной датой и временем в локальном часовом поясе пользователя; если достоверной даты нет, точное значение не выдумывать.

Текущая папка остаётся первой независимо от давности активности; остальные идут по убыванию реальной точной даты последней Kilo-активности, а не по тексту относительной подписи. Простое открытие папки не меняет дату Kilo-активности.

## 17. Одна раскрытая папка за раз

**Проблема:** несколько раскрытых папок могут вытеснить из поля зрения названия остальных.

**Принятое решение:** использовать аккордеон. Одновременно раскрыта одна папка; раскрытие следующей сворачивает прежнюю. Это помогает сохранять доступность остальных названий в списке. Плавное раскрытие/сворачивание длительностью **320 мс** (вдвое медленнее первоначальных 160 мс); компенсация прокрутки по возможности удерживает выбранную плашку и не уводит её из-под курсора. Если нужно показать начало деталей — минимальная прокрутка без прыжка вверх. При reduced motion движение отключается, устойчивость положения сохраняется. Край списка может ограничивать компенсацию.

## 18. Показать файлы папки

**Принятое решение:** действие **«Показать файлы папки»**. Подсказка при наведении: **«Откроется Проводник Windows»**. Постоянное пояснение не добавлять.

## 19. Полный путь — в подсказке названия папки

**Принятое решение:** убрать отдельную строку полного пути из раскрытых деталей. Полный путь показывать при наведении на название папки.

Компромисс: папки с одинаковыми именами придётся различать по подсказке; дополнительную функцию для этого не вводим.

## 20. Подсказка к последним диалогам

**Принятое решение:** на заголовке **«Последние диалоги»** показывать подсказку **«До трёх последних диалогов. Открыть и продолжить их можно в Kilo Code»**. Дополнительный видимый текст не добавлять.

## 21. Название диалога в одну строку

**Принятое решение:** каждое название диалога показывать в одну строку. Длинное название обрезать с многоточием, полное — показывать в подсказке при наведении.

## 22. Одно предупреждение о недоступной папке

**Принятое решение:** сохранить видимую пометку **«Папка не найдена»**, убрать повторное предупреждение внутри раскрытых деталей.

Подсказка на пометке: **«Папка не найдена по сохранённому пути. Возможно, её переместили или удалили. Открытие недоступно»**.

## 23. Обновление только значком

**Принятое решение:** показывать обновление только значком **↻**, без видимого слова «Обновить». Подсказка при наведении: **«Обновить список папок и диалогов из Kilo»**.

## 24. Соразмерность стандартному интерфейсу VS Code

**Принятое решение:** согласовать оба дизайна во всех семи темах с обычным UI-шрифтом VS Code. База B — `var(--vscode-font-size, 13px)`, семейство — `var(--vscode-font-family, 'Segoe UI', Arial, sans-serif)`, обычное начертание — `var(--vscode-font-weight, 400)`.

Действия, названия диалогов, tooltip и статус — 1B. Второстепенные даты и пометки — 12/13B (около 0,92B). Названия папок умеренно крупнее: 15/13B у «Тонких рамок», 16/13B у исходных «Монограмм». Монограммы — 32/13B и 36/13B соответственно. Заголовок Kilo Hub — 1B; «Мои папки с Kilo» — 14/13B и 15/13B. Акценты сохраняются начертанием и композицией, без крупных рекламных заголовков.

Отступы и высоты действий производны от B; узкая панель 260/320/400px не уменьшает шрифты или знаки. Название папки переносится, диалог остаётся однострочным с многоточием, содержимое прокручивается при нехватке места. Два дизайна сохраняют разные формы/плотность, их не унифицировать.
