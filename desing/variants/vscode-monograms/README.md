# Лаконичные монограммы в визуальном языке VS Code

Открыть [галерею](index.html). В каждом из пяти файлов находятся три статические панели: тёмная, светлая и высокая контрастность. Ссылки-якоря над страницей ведут к нужной демонстрации. Нужен только локальный браузер, сервер и интернет не используются.

| Вариант | Композиция |
|---|---|
| [Спокойный список](01-quiet-list.html) | Знак 32 px слева, умеренные интервалы и простые разделители |
| [Тонкие рамки](02-inset.html) | Небольшие блоки с тонкой рамкой и минимальными скруглениями |
| [Название впереди](03-heading.html) | Более крупное название слева, небольшая монограмма справа |
| [Общее поле](04-guide.html) | Знаки в отдельной колонке, детали продолжают линию названия |
| [Строка-ярлык](05-labels.html) | Маленькая монограмма над названием и вертикальная иерархия |

Reference пользователя изучен как визуальный образец сдержанного интерфейса; скриншот и его реальные metadata не копируются в макеты. Предыдущие 17 концепций сохранены. В новой серии нет декоративных цветных обложек, теней или новых функций. Текущая папка обозначена текстом и линией; missing — словами и недоступными кнопками. Разговоры пассивны, показываются до трёх последних. Раскрытие HTML `details` работает; кнопки открытия и обновления не выполняют команды.

## Темы и граница интеграции

`panel.css` использует CSS-переменные `--vscode-*` с fallback. `demo-themes.css` задаёт их значения только для автономного сравнения; это примеры палитр, а не точные копии всех встроенных тем. При будущей интеграции этот демонстрационный файл не подключается: значения должен предоставить VS Code. Самостоятельно открытый HTML **не получает текущую тему редактора**.

Связка токенов:

| Элемент | Токены |
|---|---|
| Панель и заголовок | `sideBar.background`, `sideBar.foreground`, `sideBarTitle.foreground` |
| Вторичный текст | `descriptionForeground` |
| Монограмма | парные `badge.background`, `badge.foreground` |
| Текущая папка | парные `list.inactiveSelectionBackground`, `list.inactiveSelectionForeground` |
| Наведение | парные `list.hoverBackground`, `list.hoverForeground` |
| Действия | парные `button.background` / `button.foreground`, `button.secondaryBackground` / `button.secondaryForeground` и hover backgrounds |
| Границы и фокус | `sideBar.border`, `contrastBorder`, `contrastActiveBorder`, `focusBorder` |
| Недоступность и warning | `disabledForeground`, `editorWarning.foreground` |

Названия и назначение токенов сверены с [официальным справочником цветов VS Code](https://code.visualstudio.com/api/references/theme-color). Правило преобразования имён в CSS-переменные и поддержка типов тем описаны в [документации Webview](https://code.visualstudio.com/api/extension-guides/webview#theming-webview-content). Это объясняет возможный способ будущей интеграции и не означает, что production-переход на Webview уже выполнен или выбран.

## Проверки

- `node desing/variants/vscode-monograms/build.mjs` — генерация пяти вариантов и галереи.
- `node --check desing/variants/vscode-monograms/build.mjs` — синтаксис генератора.
- `node desing/variants/vscode-monograms/verify.mjs` — 6 HTML, 5 × 3 темы, локальные ссылки и якоря, пять папок на панель, до трёх пассивных диалогов, недоступные действия, отсутствие внешних ресурсов и скриптов в HTML.
- Все 23 используемых цветовых токена заданы в каждой демо-палитре. Расчёт десяти пар текста/фона дал минимум 4,79:1 для тёмной, 5,50:1 для светлой и 15,46:1 для высококонтрастной палитры. Это проверка указанных цветов, не сертификация доступности и не доказательство работы произвольной темы.
- Визуальный рендер не подтверждён; Browser Use ранее запретил локальный URL и обходы. Повторных попыток открытия не было. Переносы, реальный фокус, масштаб и интеграция в VS Code остаются для визуальной проверки.
