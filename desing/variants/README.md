# Статические варианты Kilo Hub

Открыть `index.html` в обычном локальном браузере. Сервер, установка зависимостей и интернет не нужны. Все данные вымышлены. Кнопки ничего не открывают и не читают; раскрытие папок работает стандартным HTML `details`.

После выбора пользователем направления «Монограммы» подготовлена [отдельная галерея ещё десяти вариантов](monograms/index.html). Первые семь сохранены.

| Вариант | Отличие |
|---|---|
| [Монограммы](01-monograms.html) | Буквенные ориентиры, отдельные округлые карточки |
| [Крупный текст](02-editorial.html) | Выразительные текстовые блоки без значков и карточек |
| [Папки на столе](03-folders.html) | Силуэты папок с цветными вкладками |
| [Лента ориентиров](04-rail.html) | Вертикальные направляющие, открытая недоступная папка |
| [Мозаика](05-mosaic.html) | Плитки в две колонки; детали занимают полную ширину |
| [Рабочая тетрадь](06-notebook.html) | Крупные заголовки, контурные метки и линейные разделители |
| [Контрастные блоки](07-focus.html) | Тёмные крупные плашки, геометрические ориентиры |

[Состояния](states.html) показывают узкую панель 260 px, загрузку, пустой список, ошибку первого чтения, ошибку обновления с предыдущими данными и недоступную папку. Различия оформления в семи вариантах являются предложениями, не обязательными ограничениями для дизайнера.

Исходник для воспроизведения HTML — `build.mjs`, стили — `styles.css`. Команда из корня репозитория: `node desing/variants/build.mjs`. В браузере JavaScript не требуется. Технические подписи над макетами и страница сравнения не являются частью интерфейса расширения.

## Проверка

- Генерация всех семи вариантов, галереи и страницы состояний прошла без ошибок.
- Выполнена структурная проверка локальных ссылок, количества папок, пассивных диалогов, отсутствия внешних ресурсов и исполняемых скриптов в HTML.
- Визуальный рендер **не подтверждён**: Browser Use отклонил локальный `file` URL по политике безопасности. Обход через другой браузер или сервер не выполнялся. Перед выбором концепции требуется открыть галерею локально и проверить читаемость, переносы и масштаб.
- Production-код, `kilo.db`, исходное ТЗ и нормативные требования Step 1 не изменены.
