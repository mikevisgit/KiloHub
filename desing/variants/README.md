# Два эталона Kilo Hub

[Галерея](index.html): [Тонкие рамки](vscode-monograms/02-inset.html) в трёх темах и [исходные Монограммы](01-monograms.html) в четырёх (оригинальная, тёмная, светлая, контрастная). Остальные 20 композиций и их зависимости удалены по прямому запросу пользователя. Старые версии доступны в Git.

Открывать HTML локально; сервер, интернет и установка зависимостей не нужны. JavaScript демонстрирует аккордеон, компенсацию прокрутки и доступные подсказки. Кнопки не выполняют команды и не читают данные. Нормальный список и missing представлены в каждой теме. Остальные обязательные состояния описаны в [финальном ТЗ](../ТЗ%20реализации%20дизайна%20VSIX.md).

Сборка: `node desing/variants/build-final.mjs`. Проверка: `node desing/variants/verify-final.mjs`. Общие файлы: panel.css, refinements.css, demo-themes.css, activity.cjs, demo.js. Демо-палитры нельзя подключать в Webview будущего расширения: тему должен задавать VS Code. Монограммы сохраняют исходную композицию крупных знаков и округлых карточек; тонкие рамки — компактные блоки.

Проверены структура 2 × композиции / 7 тем, ссылки, точные тексты, отсутствие дат диалогов, даты папок и сортировка. Минимум расчётного контраста проверенных текстовых пар: original 5,54:1; dark 4,79:1; light 4,74:1; contrast 13,44:1. Это не проверка всех состояний пикселей или реальных пользовательских тем.

Визуальный рендер, живое управление клавиатурой, анимация и прокрутка в браузере не подтверждены: прежний запрет file URL не обходился. До реализации выбрать одну композицию; переключатель двух дизайнов не предлагается. Production и данные Kilo не изменялись.
После повторного аудита: исправлены пути, даты и подсказки; анимация 320 мс, последнее быстрое нажатие сохраняется. Проверка регрессий: `node desing/variants/verify-regressions.mjs`. `interaction.cjs` содержит очередь и обработчики tooltip. Timestamps примеров фиксированы в HTML; подписи актуализируются при смене дня и возвращении на страницу, не изменяя активность.
