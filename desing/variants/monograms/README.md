# Десять вариантов на основе монограмм

Пользователь сравнил первые семь концепций и выбрал `01-monograms.html` как наиболее понравившееся направление. Эта серия исследует его дальше, не фиксируя окончательное решение.

Открыть [локальную галерею](index.html). Старые семь вариантов сохранены. Каждый новый HTML использует локальные `../styles.css` и `monograms.css`; интернет и сервер не нужны.

1. [Большой знак](01-signature.html) — увеличенный квадрат и крупное название рядом.
2. [Круги](02-circles.html) — круглые буквенные знаки и мягкие свободные карточки.
3. [Цветная шапка](03-banner.html) — имя слева, знак справа, отдельная цветная область идентичности.
4. [Контур](04-outline.html) — контурные знаки и строгий список без карточечных фонов.
5. [Поле слева](05-margin.html) — компактный знак и отдельная вертикальная колонка деталей.
6. [По центру](06-centered.html) — знак над названием, центрированная композиция.
7. [Ночные знаки](07-night.html) — контрастные знаки на тёмных плашках.
8. [Билеты](08-ticket.html) — буквенный корешок и плотная компоновка.
9. [Два масштаба](09-duet.html) — крупное буквенное поле и асимметричный блок названия.
10. [Ярлыки](10-label.html) — буквенная вкладка над крупным заголовком.

Общие функции и данные одинаковы для сравнения: пять вымышленных папок, текущая первой, три последних пассивных диалога (у недоступной папки один), три действия, ручное обновление. HTML `details` позволяет раскрывать папки, кнопки команды не выполняют. Смысл недоступности и текущего места передан текстом, а не только цветом.

Перегенерация из корня: `node desing/variants/monograms/build.mjs`. Проверены синтаксис генератора, наличие десяти вариантов, локальные ссылки, состав папок/диалогов, недоступные действия, отсутствие внешних URL и скриптов в HTML. Визуальный рендер не подтверждён; повторное браузерное открытие не выполнялось после отказа Browser Use на локальный URL в первой серии. Все варианты требуют просмотра пользователем перед выбором; никакая концепция не заявляется окончательной.
