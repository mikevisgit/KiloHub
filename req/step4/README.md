# Step 4: поддержка macOS

## Статус

Step 4 является отложенной задачей после завершения Step 3. 22 сентября 2026 года добавлено повторное исходниковое исследование по выпущенному Step 3 `0.3.2`; реальные macOS-проверки Gate 0 ещё не выполнены. Production-код, поддерживаемые платформы и дистрибутивы не изменяются.

Нормативный документ: [01-requirements.md](01-requirements.md). Последовательный план: [../../specs/step4-implementation-plan.md](../../specs/step4-implementation-plan.md). Предварительные доказательства: [../../docs/step4-preliminary-discovery.md](../../docs/step4-preliminary-discovery.md).

Актуальное исследование: [Step 4 по baseline 0.3.2](../../docs/step4-discovery-0.3.2.md). Содержит точный source/VSIX/hash, схему 3, карту Windows-зависимостей, риски IPC/GC/permissions и матрицу M01–M12. Оно закрывает исходниковую фиксацию baseline, но не заменяет нативное discovery и итоговую приёмку Step 3.

## Обязательное условие входа

До любых изменений production-кода необходимо завершить Step 3, зафиксировать его точный source commit и VSIX, а затем полностью повторить discovery переносимости по фактической реализации Step 3. Одного исходникового исследования недостаточно: реализованные собственная база Hub, синхронизация, поиск, межоконная координация и recovery требуют проверки на обеих нативных macOS-архитектурах.
